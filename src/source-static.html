R 프로그래밍·파이썬 시험 대비 통합 정리

R과 Python의 기본 개념과 구현 연습을 함께 공부하는 학습서입니다. ★는 핵심 개념입니다. 수업·시험의 실제 범위와 방식은 담당자의 공지를 우선하세요.

1. 우선순위

  1. R 중간: 자료구조의 차이, 벡터·행렬 만들기와 인덱싱, 조건 추출, which, subset, apply, for/while, airquality 실습.
  2. 파이썬 중간: 입력·형변환, 연산자, 조건·반복·함수, 문자열과 리스트 인덱싱, 2차원 리스트, 누적·개수 세기, 패턴과 알고리즘을 직접 구현하는 연습.
  3. 기말까지: R은 기술통계·결측값·시각화·회귀·군집·분류. 파이썬은 클래스, 예외·파일, NumPy·pandas, 정렬 및 문제에 맞는 알고리즘.

2. R 기본 개념 ★

  • R은 통계 분석과 시각화에 쓰는 언어이며 운영체제에 종속된 언어가 아니다. RStudio는 R을 사용하는 개발 환경이다.
  • 데이터 분석: 데이터 준비 → 가공·전처리 → 분석 → 결론. 행은 보통 관측 대상, 열은 변수, 셀은 한 관측값이다.
  • 자료의 구분: 범주형은 혈액형·성별처럼 종류를 나타내고, 양적 자료는 키·온도처럼 수량을 나타낸다. 범주형에도 순서가 없는 명목형과 순서가 있는 순서형이 있다.
  • 빅데이터의 3V: 양(Volume), 속도(Velocity), 다양성(Variety). 과거 기출 회상에 등장한다.
  • 변수는 값을 담는 이름. x <- 3; 대소문자를 구분한다. 보통 영문자로 시작하고 이후 영문자·숫자·.·_ 사용. .으로 시작할 수 있지만 그 다음 문자가 숫자이면 일반적인 이름으로 쓸 수 없다. 공백·-는 일반적인 이름에 쓰지 않는다.
  • 함수는 입력을 받아 작업을 수행한다. 인자가 없는 함수도 가능하고 함수를 변수에 저장할 수도 있다. 패키지는 함수와 데이터 등을 묶은 단위이며 install.packages("패키지")는 설치, library(패키지)는 불러오기다.
  • RStudio에서 스크립트 편집 후 Ctrl+Enter는 현재 줄 또는 선택 영역 실행.

자료의 R 요약에는 13과 4의 나머지를 묻고 13 %% 3이라고 쓴 오타가 있다. 올바른 식은 13 %% 4다. =은 할당에 쓸 수 있지만 비교는 ==이다. &&, ||는 첫 원소만 사용하는 단축 평가이므로 벡터의 각 원소를 비교할 때는 &, |를 쓴다.

4. R 반복문·함수·apply ★

total <- 0
for (i in 1:100) {
  if (i %% 3 == 0) total <- total + i
}
total                       # 1683
length(which((1:100) %% 3 == 0))  # 33

i <- 1; total <- 0
while (i <= 100) {
  if (i %% 3 == 0) total <- total + i
  i <- i + 1
}
square <- function(x) { x^2 }

if 조건은 길이 1인 논리값이어야 한다. break는 반복 종료, next는 다음 반복으로 이동한다. apply(행렬, 1, 함수)는 행별, apply(행렬, 2, 함수)는 열별이다. 데이터프레임에 apply를 쓰면 행렬로 변환되므로 서로 다른 형의 열이 함께 있으면 형 변환에 주의한다.

m <- matrix(1:6, nrow=2)
apply(m, 1, sum)        # 행별 합: 9, 12
apply(m, 2, mean)       # 열별 평균: 1.5, 3.5, 5.5
rowSums(m); colSums(m); rowMeans(m); colMeans(m)

6. R 기말·통계 범위

  • mean, median, sd, var, min, max, quantile을 구분한다. mean(x, trim=0.15)는 양쪽 끝에서 각각 15%를 제거한 절사평균이다. 표준편차는 값이 평균에서 얼마나 퍼졌는지 나타낸다.
  • hist(x)는 수치 자료의 구간별 분포, boxplot(x)은 중앙값·사분위수·이상치, barplot(table(x))은 범주별 빈도, plot(x,y)는 산점도다. 상자그림의 일반적인 이상치 경계는 Q1−1.5×IQR, Q3+1.5×IQR이고 IQR=Q3−Q1이다.
  • cor(x,y, use="complete.obs"): 상관계수는 −1~1. 부호는 방향, 절댓값은 선형 관계의 강도이며 상관관계만으로 인과관계를 결론내리지 않는다.
  • 회귀: fit <- lm(Volume ~ Girth, data=trees)에서 왼쪽이 예측 대상, 오른쪽이 설명 변수. summary(fit), predict(fit, newdata=data.frame(Girth=c(8.5,9,9.5))). 기울기는 x가 1 늘 때 예측 y의 변화량.
  • k-평균은 비지도 학습으로 비슷한 관측값을 k개 군집으로 묶는다. 거리 기반이라 단위 차이가 크면 스케일링이 중요하다. 0~1 정규화는 (x-min(x))/(max(x)-min(x))이고 최댓값과 최솟값이 같으면 0으로 나누지 않도록 따로 처리한다.
  • k-NN 분류는 가까운 훈련 데이터 k개의 레이블을 이용한다. 훈련/시험 데이터를 분리하고 mean(pred == actual)로 정확도를 평가한다. 학습·시험 데이터의 전처리는 훈련 기준으로 맞춘다.

9. 파이썬 함수·재귀 ★

def add(a, b):
    return a + b

def collatz(n):
    print(n, end=" ")
    if n == 1:             # 종료 조건 필수
        return
    if n % 2:
        collatz(3 * n + 1)
    else:
        collatz(n // 2)

매개변수는 함수 정의의 이름, 인자는 호출할 때 전달한 값이다. return은 결과를 돌려주며 함수를 끝낸다. print는 화면에 출력할 뿐 반환값이 아니다. 재귀는 종료 조건과 더 작은 문제로 가는 규칙을 확인하고, 입력이 커지면 재귀 깊이 제한을 고려한다.

10. 로컬 연습문제 6가지의 핵심 ★

  1. 누적합 경계: 다음 수를 더한 합이 입력 이하일 때만 더한다. 예: 55이면 1~10의 합이므로 10. while total + i <= limit:로 다음 값을 검사한다.
  2. 모래시계 별: n=5일 때 별 개수 9,7,5,3,1,3,5,7,9. 윗부분 행 i에서 공백 i개, 별 2*(n-i)-1개. 아랫부분은 순서를 거꾸로 하되 가운데를 중복 출력하지 않는다.
  3. 3·6·9: 문제는 숫자에 3·6·9가 포함되면 X 하나를 출력한다. any(c in str(i) for c in "369"). 3의 배수 판정과 다르다.
  4. 출석 빈도: 1~23 크기의 카운터를 만들고 입력된 각 번호마다 증가. 입력 데이터 개수와 번호 범위를 문제 조건에 맞게 확인한다.
  5. 콜라츠 재귀: 위 함수처럼 홀수면 3*n+1, 짝수면 n//2, 1에서 중단. 5 → 5 16 8 4 2 1. 모든 자연수에 대한 종료는 일반적으로 증명된 사실이 아니다.
  6. 시저 암호 복호화: 소문자라면 chr((ord(ch)-ord('a')-3)%26+ord('a')), 공백 등은 유지한다. qhyhu → never. 범위가 대문자까지 포함되는지는 문제 조건을 확인한다.

11. 기출 유형별 알고리즘 ★

  • 문자 치환: 2022 Atbash는 a↔z, A↔Z, 0↔9. 영문·숫자 외 입력의 처리 조건을 반드시 구현한다. 2023은 키를 반복해서 각 문자에 대응시킨다. key[i % len(key)]로 키 순환, A~Z는 0~25로 바꿔 계산한다. 구체적인 이동 규칙은 원문 예시로 확인한다.
  • 좌표 시뮬레이션: (x,y)를 0에서 시작해 U/D/L/R 명령을 split(','), strip()으로 나누고 방향·거리를 파싱. 잘못된 명령은 오류 처리한다. 그리드 문제는 행·열과 x·y 순서를 명시한다.
  • 큐: FIFO(먼저 넣은 것부터 꺼냄). 최대 크기에서 삽입하면 overflow, 빈 큐에서 삭제하면 underflow. 리스트 구현은 append, pop(0)이고 긴 큐에는 collections.deque가 효율적이다.
  • 틱택토: 3×3 판, 빈 칸 확인, 차례 교대, 각 행·열·대각선 검사, 승리 또는 빈 칸이 없을 때 무승부. 무작위 선택은 남은 빈 칸 중에서만 한다.
  • 2024 연속 부분배열 합: 음수가 있으므로 일반적인 양수 전용 투 포인터만으로는 안 된다. 누적합과 딕셔너리: 현재 누적합 p에서 p-S가 앞에 있으면 그 다음 위치부터 현재 위치까지의 합이 S다. 초기 {0: -1}을 두어 0번부터 시작하는 경우도 처리한다.
  • 2024 별 패턴: 입력별 그림을 보고 행·열의 좌표 규칙, 반복 단위, 앞뒤 대칭을 찾아야 한다. 중첩 반복문을 쓰고 n=1,2,3,4와 더 큰 값으로 검증한다. 그림의 모든 규칙은 원본 PDF를 직접 확인한다.
  • 2025 행렬: 덧셈·뺄셈은 두 행렬 크기가 같아야 하고, A가 m×n, B가 n×p일 때 곱은 m×p. C[i][j] = sum(A[i][k]*B[k][j] for k in range(n)). 전치 결과는 T[j][i] = A[i][j]. 문제는 외부 모듈을 금지했다.
  • 2025 원형 접시: 시작 i의 K개 합은 sum(a[(i+j)%n] for j in range(k)). K>N도 나머지 연산으로 처리된다. 모든 시작점을 비교하고 동점 규칙을 정한다. 반복합은 초기 합에서 빠지는 원소를 빼고 새 원소를 더해 최적화할 수 있다.
  • 2025 RLE: 같은 문자가 연속된 구간을 찾고 길이 2 이상이면 길이+문자, 1이면 문자만. 디코딩은 여러 자리 숫자를 끝까지 읽고 뒤의 영문자 하나를 반복한다. 빈 문자열·잘못된 토큰과 ValueError를 확인하고, 문제의 슬라이싱 의무를 지킨다.
def find_subarray_index(array, target):
    seen = {0: -1}
    prefix = 0
    for i, value in enumerate(array):
        prefix += value
        if prefix - target in seen:
            return seen[prefix - target] + 1, i  # 양 끝 인덱스 포함
        if prefix not in seen:
            seen[prefix] = i
    return None

2025 원형 접시 기출의 예시 수치는 정의와 맞지 않는다. [2,1,4,3,5], K=3이면 각 합은 7, 8, 12, 10, 8이다. K=8이면 22, 23, 27, 25, 23이다. 문제 규칙을 따라 계산하고 예시 오타를 그대로 외우지 않는다.
